Primera versión pública. Editor de Markdown nativo, minimalista y libre de distracciones
para Windows — port del editor [Apostrophe](https://gitlab.gnome.org/World/apostrophe) de
GNOME, construido con **Tauri 2 + Rust**.

Sin Electron, sin dependencias que instalar, sin cuenta. Descargas, instalas y escribes.

## Instalación

Descarga **`Apostrophe_0.1.0_x64-setup.exe`** (recomendado) o el `.msi` si prefieres
desplegarlo por directiva. Se instala por usuario: no pide permisos de administrador.

> ### "Windows protegió tu PC" — es normal
>
> El instalador **no está firmado**, y es una decisión deliberada: este es un proyecto
> libre y personal. Un certificado de firma de código cuesta entre 200 y 400 dólares al
> año y no hace la aplicación más segura — solo le quita un clic de fricción a quien la
> descarga.
>
> Windows SmartScreen mostrará una pantalla azul diciendo "Editor desconocido". Para
> continuar: **Más información** → **Ejecutar de todas formas**.

## Qué incluye

**Editor**
- CodeMirror 6 con resaltado de Markdown en vivo
- Modo enfoque (atenúa todo menos el párrafo actual), modo Hemingway y pantalla completa
- Buscar y reemplazar, y comandos de formato Markdown
- Corrector ortográfico en español (Hunspell puro-Rust, F7 para activarlo)
- Estadísticas: caracteres, palabras, oraciones, párrafos y tiempo de lectura

**Vista previa**
- Vista dividida, solo editor o solo vista previa (Ctrl+P)
- Renderizado con pandoc, incluyendo matemática

**Exportación** (Ctrl+E)
- **PDF, HTML, ODT, DOCX, EPUB y LaTeX** — el formato se elige en el desplegable
  "Guardar como tipo"
- El PDF y el HTML conservan la tipografía de la vista previa
- Todo lo resuelven los motores incluidos: no necesitas instalar pandoc, LaTeX ni nada más

**Archivos**
- Asociación con `.md` y `.markdown`: doble clic y abre
- Lee archivos con codificación no UTF-8 (Latin-1, Windows-1252, UTF-16)
- Autoguardado periódico con recuperación tras un cierre inesperado
- Avisa y recarga si el archivo cambia en disco desde fuera de la aplicación
- Recuerda tamaño y posición de la ventana

**Personalización**
- Temas claro, oscuro y sepia
- Ventana de atajos de teclado (Ctrl+?)

## Requisitos

Windows 10 o superior con WebView2 Runtime, que viene preinstalado en las versiones
modernas de Windows 10 y 11.
